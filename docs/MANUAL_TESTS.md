# Manual Browser Test Checklist

Run the app locally at `http://localhost:5173` with the Supabase schema applied. For auth tests, use inboxes you can access and a temporary test-only password. Turn off email confirmation only for local testing.

Use a fresh Supabase account with no other subjects for the GWA tests. Other subjects without numeric final grades affect the displayed uncounted-unit total.
